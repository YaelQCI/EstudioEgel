# Apuntes por área

Se crearán conforme se estudien los temas, usando estos nombres:

- 01-analisis/
- 02-diseno/
- 03-desarrollo/
- 04-gestion/
- 05-comprension-lectora/
- 06-redaccion-indirecta/

Cada apunte debe incluir objetivo, explicación breve, ejemplo, distinciones que suelen confundirse, fuentes y preguntas de recuperación. Todavía no hay temas estudiados registrados.
