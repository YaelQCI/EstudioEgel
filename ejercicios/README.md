# Ejercicios y simulaciones

Diagnóstico inicial pendiente. No hay ejercicios contestados ni resultados registrados todavía.

## Organización

Crear archivos con fecha y tema, por ejemplo `2026-11-11-diagnostico-preguntas.md`, y un archivo separado para soluciones y explicaciones. Añadir las soluciones después de que se responda el bloque o mantenerlas separadas para evitar verlas durante el intento.

## Cada bloque debe registrar

- Área y subárea.
- Fuente o indicación de que son preguntas originales de práctica.
- Tiempo previsto y tiempo real.
- Respuestas elegidas y confianza.
- Resultado y explicación de cada opción.
- Errores que se trasladan al registro de seguimiento.

Usar preguntas con tres opciones y una respuesta correcta para practicar el formato de la guía. Los ejercicios originales no son preguntas oficiales ni predicen el resultado del examen.
